> 目录名沿用 `game-v8`，文档版本为 **v16**。

- **第一章 G01–G03**：**2D 像素风**（Canvas2D，武汉江滩像素图 + 扫描线 + 白色蛛丝）。
- **第二章 G04–G09**：**3D 第一人称**（Three.js r160，程序化低模）。
- **第三章 G10–G11**：**3D 第一人称**。
- 自动音频卡位：`bgm_*` / `vo_d01–d12` / `sfx_*`（Ogg Opus 优先，含 m4a 回退）；`v0.mp4` 真实播放，`v1–v4` 用 `public/comics/*.webp` 漫画图替代。
- 资源已压缩：音频约 2.6 MB（Ogg，另有 2.7 MB m4a 回退）、漫画/像素图 WebP 约 1.14 MB（v4/悟空 720p，其余 360p）、boot WebP 1920×1080、v0 960×540；`public` 总计约 8.3 MB。

## 运行

```bash
cd game-v8
npm install
npm run dev
```

或双击 `dev.bat`；构建 `build.bat` + `preview.bat`。

## 操作

| 按键 | 动作 |
| :--- | :--- |
| `WASD` | 移动（3D 第一人称 / 2D 左右横移 + 前后） |
| 鼠标 | 3D 视角（点击画面锁定） |
| `Space` | 跳跃 |
| `E` / 右键 | 蛛丝摆荡 |
| 左键 / `J` | 蛛网弹 |
| `Shift` | 闪避 |
| `F` | 交互 / 关对白 |
| `H` / 右上 💡 | 提示卡（当前步骤 + 重试本段） |
| `P` / `Esc` | 暂停 |
| `R` | 重新开始 |
